# 《命中注定的离别》评委一页纸（对齐官方计分）

## 总分构成

| 组成 | 占比 | 说明 |
|------|------|------|
| **评委评分** | **70%** | 知乎特邀评委权重 ×2，其余评委按普通系数加权平均 |
| **用户选择** | **30%** | 最终 **Agent 用户数**（**OAuth 授权登录数**） |

---

## 评委评分三维度（合计 100%，再折算进 70%）

| 维度 | 权重 | 本项目如何对应 |
|------|------|----------------|
| **A2A 场景价值** | **40%** | 宿命推演由 **user_agent 与 partner_agent 双分身轮流出牌**（`a2aTurns`），三阶段（初遇/冲突/离别）均为 **Agent 间自主对话**，非单次工具调用生成旁白。 |
| **创新度** | **30%** | MBTI + 八字/卦象 + **「先看离别」**悲剧预演 + 小说/漫画/知乎建议多模态闭环。 |
| **完成度** | **30%** | SecondMe OAuth → 分身降生 → A2A 推演时间轴 → 结果页可跑通；外部 API 失败时 Mock 降级保证 Demo 不崩。 |

---

## 用户选择（30%）——拉 OAuth

- **计分口径**：完成 **SecondMe OAuth 授权**的用户数。  
- **产品动作**：首页与流程首屏强调「**先登录**」；分享落地页指向带登录入口的 URL；生产环境配置好回调地址。

---

## 5 分钟 Demo 建议顺序

1. 打开站点 → **SecondMe 登录**（强调计入用户选择）  
2. **分身降生**（MBTI + 生日 + 出生地）  
3. **宿命推演**（展示双 Agent 对话气泡 + 卦象）  
4. **结果页**（小说 + 漫画占位/生图 + 知乎建议）

---

## 技术锚点（评委追问时可答）

- A2A：`src/lib/simulation-engine.ts` 分阶段串行调用，每阶段 LLM 输出 **JSON：`turns` + `summary` + `emotionIntensity`**。  
- OAuth：`/api/auth/secondme/*` + Cookie 存 token；`/api/secondme/profile` 写 `secondme_user_id`。

## 演示模式（现场稳定）

- 环境变量：`DEMO_MODE=true`（可选同步 `NEXT_PUBLIC_DEMO_MODE=true` 用于首页条）
- 效果：跳过外部 LLM、推演直接返回 `src/lib/demo-data.ts` 固定 A2A 对话；生图走占位图
- 一键写入浏览器：`GET /api/demo-bundle` 或访问 `/demo` 页加载演示包
